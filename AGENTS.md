# SCE engineering rules

Work only within this independent repository. Preserve requested, planned,
executed, produced, verified, and unknown information separately. Never turn a
proposed capability into an implemented or verified capability without evidence.
Use PowerShell 7 on Windows. Use the project virtual environment. Run the
automated suite and controlled build experiment for behavioral changes. Do not
install acquired software or run untrusted source merely to inspect it. PREPARE
is read-only; execution, verification, packaging, and installation are distinct.
Do not modify other Codex sessions or unrelated repositories.
